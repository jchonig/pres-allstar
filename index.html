AllstarLink

Repeaters, Hotspots and Nodes, Oh My!

Jeffrey Honig — N2VLV

n2vlv.net — n2vlv@honig.net

Welcome everyone. Today we'll be talking about AllStar Link, a VoIP-based system for linking amateur radio repeaters and nodes.

What is AllstarLink?

  • VoIP interconnect system for amateur radio
  • Based on Asterisk PBX software
  • Links repeaters, hotspots, and nodes worldwide
  • Open source and free to use
AllstarLink uses the open-source Asterisk telephony engine adapted for amateur radio use.

History / Background

  • Created by Jim Dixon, W6JL
  • Built on the Asterisk open-source PBX
  • First released in the early 2000s
  • Now maintained by the AllstarLink community
Jim Dixon saw the potential of using VoIP and open-source telephony software to link amateur radio systems.

Compare to EchoLink and IRLP

  • EchoLink — PC/mobile app, simple to use, closed source
  • IRLP — Dedicated hardware, Linux-based, node-to-node
  • AllstarLink — Most flexible, open source, Asterisk-based
  • AllstarLink can link to EchoLink nodes
Compare the three main VoIP linking systems. Each has trade-offs in complexity vs. flexibility.

Architecture

  • Servers run Asterisk with app_rpt module
  • Nodes connect to radios via audio interfaces
  • Nodes register with the AllstarLink network
  • Audio transported over the internet as VoIP
Radio → Interface → Computer/Node → Internet → Node → Interface → Radio.

Addressing

  • Each node gets a unique node number
  • Originally 5-digit numbers
  • Now also 6-digit numbers as the network grows
  • Node numbers used for connecting and DTMF commands
Node numbers are how you identify and connect to other stations.

Uses

  • Access to a remote repeater
  • Personal hotspot
  • Linking two or more repeaters
  • Conference bridges / hubs
  • Remote base station
AllstarLink is versatile — from a simple hotspot on your desk to linking repeater networks across states or countries.

Hardware

  • Raspberry Pi (or other Linux computer)
  • USB sound/radio interface (URI, modified CM108)
  • Radio (for hotspot or repeater connection)
  • Internet connection
A basic node can run on a Raspberry Pi with a USB interface and an inexpensive radio.

Software

  • ASL3 — Current official AllstarLink distribution
  • HamVoip — Alternative distribution, Arch Linux based
  • Both based on Asterisk with app_rpt
  • Debian/Raspberry Pi OS (ASL3) vs. Arch Linux (HamVoip)
Two main software options. ASL3 is the current community standard. HamVoip is an alternative with its own following.

Linking to EchoLink

  • AllstarLink nodes can connect to EchoLink
  • Bridges the two networks together
  • Expands reach to EchoLink users worldwide
This interoperability is a big advantage of AllstarLink.

Digital Radio Integration

  • AllstarLink is primarily analog FM
  • DVSwitch — Bridge to DMR, D-STAR, YSF, P25, NXDN
  • Connects analog AllstarLink to digital networks
  • Other digital bridge solutions available
DVSwitch and similar tools let AllstarLink nodes interoperate with digital voice modes.

DTMF Commands

  • Control your node from the radio keypad
  • Connect to a node: *3node#
  • Disconnect: *1node#
  • Status, link info, and more
DTMF commands are the primary way operators interact with AllstarLink from the radio side.

Monitoring

  • allmon3 — Web-based node monitor and control panel
  • supermon-ng — Enhanced web dashboard
  • See connected nodes, link status, and activity
  • Control connections from a browser
Both provide web interfaces for monitoring and managing your AllstarLink node remotely.

Hubs and Networks

  • Hubs are always-on conference nodes
  • Connect to a hub to talk with a group
  • Regional and special-interest networks
  • Examples: WIN System, HubNet, etc.
Hubs provide community gathering points on AllstarLink.
