Welcome everyone. Today we'll be talking about AllStar Link, a VoIP-based system for linking amateur radio repeaters and nodes.

What is AllStar?

  • VoIP interconnect system for amateur radio
  • Based on Asterisk PBX software
  • Links repeaters, hotspots, and nodes worldwide
  • Open source and free to use
AllStar Link uses the open-source Asterisk telephony engine adapted for amateur radio use.

How It Works

  • Each node gets a unique node number
  • Nodes connect over the internet
  • DTMF commands control connections
  • Audio is transported as VoIP
Explain the basic architecture: radio to node to internet to node to radio.

Getting Started

  1. Register at allstarlink.org
  2. Get a node number
  3. Set up hardware (Raspberry Pi, USB sound device)
  4. Install and configure ASL software
